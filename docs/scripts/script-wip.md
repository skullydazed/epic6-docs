# Script documentation: work in progress

## Synopsis

```text
/load <script>
```

`<script>` is a placeholder for the script being documented. See [load](../command/load.md); the command is registered and implemented in [source/commands.c](../../source/commands.c).

## Work in progress

If a script’s documentation is incomplete, read its source to determine whether it provides something you can use. Bundled scripts are in the [script directory](../../script/).
