# Getting EPIC

EPIC6 is a programmable IRC client. Older EPIC4 and EPIC5 scripts are not automatically interchangeable with it: EPIC6 has removed or changed interfaces, so use documentation and scripts appropriate for the client generation you intend to run. [KNOWNBUGS](../KNOWNBUGS.md) and [UPDATES](../UPDATES.md) describe interface changes and retirements.

The project's documentation entry point is [epicsol.org](https://epicsol.org/).

## EPIC6 source through Git

Clone the EPIC6 source repository:

```sh
git clone https://git.epicsol.org/epic6.git
cd epic6
```

This creates a source checkout, not an installed executable. See [basic Git for CVS users](basic_git_for_cvs_users.md) for updating a checkout and producing patches.

## Historical EPIC4 and EPIC5 source locations

Release archives for the older EPIC4 and EPIC5 generations:

- [EPIC4 production archive](https://ftp.epicsol.org/pub/epic/EPIC4-PRODUCTION/).
- [EPIC5 production archive](https://ftp.epicsol.org/pub/epic/EPIC5-PRODUCTION/).

The corresponding Git repository addresses are:

```sh
git clone https://git.epicsol.org/epic5.git
git clone https://git.epicsol.org/epic4.git
```
